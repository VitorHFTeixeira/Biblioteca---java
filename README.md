# Sistema Web para Gerenciamento de Livros

Sistema web de gerenciamento de biblioteca desenvolvido em Java com JSP, Servlets, JDBC e MySQL.

A aplicação permite o gerenciamento completo de livros, incluindo cadastro, listagem, busca, edição, exclusão e upload de
capas.

## Funcionalidades

- Cadastro de livros
- Listagem de livros cadastrados
- Busca de livros por ID
- Edição de registros
- Exclusão de livros
- Upload e exibição de capas dos livros

## Arquitetura

O projeto foi desenvolvido seguindo o padrão MVC (Model-View-Controller):

- **Model:** representação dos dados (Livro)
- **DAO:** comunicação com o banco de dados
- **Controller:** Servlets responsáveis pelas requisições
- **View:** páginas JSP e HTML

## Tecnologias utilizadas

- Java
- JSP
- Servlets
- JDBC
- MySQL
- HTML
- CSS

## Observação

As imagens das capas dos livros são armazenadas na pasta `capa` dentro da aplicação.
